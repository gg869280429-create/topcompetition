# 管理员功能补充（2026-11-12）

## 功能

1. 竞赛管理点击草稿竞赛的“发布”，可选择“同步发布新闻”，默认关闭。开启时预填竞赛标题和简介，可编辑新闻标题、正文，必须填写 HTTP/HTTPS 比赛官网。竞赛状态变更、新闻创建及发布、关联操作历史在同一事务完成；新闻无效时整体回滚。并发或重复发布仍受竞赛状态及行锁约束。同步发布后，封面及首页轮播继续在现有新闻管理中设置。
2. 报名管理保留审核通过时选择最终教师，并对已通过报名增加“选择指导教师”。未分配报名可以确认教师；已有指导可以调整教师，多位教师时选择被调整的指导关系。展示当前指导及剩余名额，名额用完或已指导该团队的教师不可选。调整或偏离意向时必须填写原因。复用原分配、调剂接口，继续遵守专业权限、名额、状态及通知规则，保留历史。已结束或已取消竞赛禁止操作。
3. 系统管理员、专业管理员侧边栏底部新增“大师工作室”，仅展示“敬请期待”。短屏下保持底部入口可见，其余菜单支持滚动。学生、教师不展示菜单，直接访问受角色路由限制。

## 接口和数据

新增 `POST /api/competition/{id}/publish`，仅系统管理员及有该竞赛维护权限的专业管理员可调用：

```json
{
  "syncNews": true,
  "news": {
    "category": "NEWS",
    "title": "竞赛新闻标题",
    "content": "竞赛说明",
    "officialUrl": "https://example.org/contest"
  }
}
```

不同步时只传 `{"syncNews":false}`。同步成功返回新闻 ID，不同步返回空数据。原竞赛状态流转接口保持兼容。

本批复用现有竞赛、新闻、指导、名额和历史表，无需变更数据库结构，也未修改或删除本地业务库中的数据。集成测试写入独立测试库。

## 指导老师称呼及展示统一

按后续要求，产品界面移除“意向教师”栏及“最终教师”称呼，统一使用“指导老师”。报名列表、报名详情通过后端返回的 `guidanceTeacherNames` 展示已确认的有效或已完成指导关系；未确认显示“待分配”，调剂后不再展示已结束的原指导老师。报名及审核仍保留管理员确认和名额校验，审核和分配弹窗不再重复展示报名选择的老师。竞赛、指导、获奖页面、校验及新发送的通知同步统一称呼。

兼容原报名请求及历史数据，无需改表。原 `preferredTeacherId` 等接口字段保留供报名选择与审核使用，列表及详情不再将它们当作已确认的指导关系展示。
