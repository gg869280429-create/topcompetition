# 教师、学生首页和竞赛预览调整

- 师生菜单“新闻资讯”改名为“竞赛预览”，沿用 `/content` 地址和角色权限，浏览器标题同步更新。
- 原首页竞赛卡片提取为 `CompetitionPreview.vue`，在师生竞赛预览中展示，保留竞赛详情、教师信息、竞赛文件和学生报名跳转；管理员首页复用该组件。
- 师生首页展示新闻轮播，包含封面、标题、正文摘要、发布时间、查看详情及新标签打开的比赛官网。
- 轮播继续读取已有的 `/api/content/carousel`：仅已发布且开启轮播的 NEWS，封面、官网及排序继续由管理员新闻管理维护。下线后按原有轮询更新移出；无数据时显示空态。
- 新闻详情继续调用受原有权限控制的内容和封面接口，不增加表、字段或业务数据。
- 管理员及专业管理员的新闻管理保留新增、编辑、发布、下线等原有功能。

验证：前端 `npm run build` 通过；Edge 浏览器使用拦截的新闻/竞赛测试响应完成 28 项断言，包括四角色导航、轮播切换、详情及官网、竞赛详情、学生报名跳转、教师无报名按钮、空轮播和窄屏布局，没有未捕获页面错误。模拟响应仅用于浏览器验收，不写入业务库。既有构建大包警告仍存在。
