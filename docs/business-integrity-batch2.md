# 第二批业务闭环

已实现成员邀请接受、拒绝和撤销，草稿不预占正式资格，正式提交重新验证全部参赛规则。新增成员必须重新接受邀请。

报名审核与每次提交保留不可变历史；取消保留报名和成员记录。已通过队伍必须先申请调整并填写原因，再确认成员和重新审核。

退赛由队长申请、所属专业管理员或系统管理员审批。批准时与有效指导关系结束、资格释放、历史和通知在同一事务中；重复批准不重复释放。有效获奖阻止退赛及调整。退赛重新申请限报名窗口，成员必须重新确认。

获奖要求日期和统一文件服务证明材料；驳回后可编辑重提，已通过只能填写原因后更正重审或撤销，保留旧值、新值和审核意见。所有物理删除获奖请求均拒绝；一队一竞赛一次获奖约束保留。
