## 历史资料兼容及补录

- **竞赛专业**：历史竞赛保持空值，展示“待补录专业”，不猜测竞赛归属。管理员可在“竞赛管理 → 所属专业 → 补录”维护分类；已结束、已取消的历史竞赛也支持该独立入口。该操作只改展示分类、保留状态和规则，记录操作历史；发布人或指定负责人管理其竞赛，系统管理员统一管理。
- **报名专业**：不根据竞赛分类修改报名归属。现有报名 ID 71 的报名专业及队长专业缺失，必须先核实真实专业再补录；不得分配到任意专业来绕过审核范围。
- **旧成果**：迁移将原成果标记为 `legacy_record=1`，保持原 ID、状态、审核意见、时间、专业和团队快照。旧记录继续按原历史范围查阅，页面明确提示实际获奖人员、指导教师或材料尚待补录。旧资料未明确的获奖学生、教师不自动生成新关联，不计入新增的获奖学生数和教师指导成果数。
- **旧成果补录**：管理员在原成果上编辑重提（草稿/驳回），或通过“更正重审”（已通过）补成果名称、实际获奖学生、指导教师、日期和材料。已结束竞赛仍可申报；报名必须审核通过且未退赛，教师须有有效或已完成指导关系。更正后恢复待审核，原值及原因保留。旧日期若错误地晚于当前时间，应核实后一起更正。
- **获奖材料**：证书、报名官网截图、恰好两张过程照片必传；官方获奖名单可选。材料需经统一上传服务获得文件 ID；迁移不伪造或猜测材料，不把不存在的文件当作可下载文件。
- **旧新闻**：保持原发布状态，不猜测官网链接和封面；默认不轮播。需要补录时先下线、补官网和封面、再发布。重新发布 NEWS 必须具备有效 HTTP/HTTPS 官网，开启轮播还需封面。
- **旧指导**：原 ACTIVE/ENDED 状态不自动变成 COMPLETED。按迁移时现有成员生成基线快照；历史缺失的成员变更过程不能据此还原，保留原记录供人工核实。此后每次分配保留快照，教师完成指导只释放一次名额。
