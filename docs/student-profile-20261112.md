# 学生个人信息与轮播样式验收（2026-11-12）

## 学生个人信息

学生左侧菜单依次为“首页、竞赛预览、报名管理、获奖管理、个人信息”。“个人信息”地址 `/profile`，仅学生可以访问；点击顶部头像或用户下拉菜单中的“个人信息”也能进入，头像支持键盘操作。其他角色沿用原导航。

个人信息页参考木马课堂个人设置的白色资料面板及行式展示，顶部显示姓名与专业，下面分别展示基本信息及账号安全。姓名、手机号、邮箱点击“修改”后单独编辑，取消不保存；账号、专业只读，由管理员维护。后端根据登录身份确定用户，提交其他用户 ID、角色、专业、账号或状态不会改变这些字段。修改姓名不回写历史报名、成果或操作记录的人员快照。

| 方法 | 接口 | 用途 |
| --- | --- | --- |
| GET | `/api/student/profile` | 读取本人资料，不返回密码及登录版本 |
| PUT | `/api/student/profile` | 修改本人姓名、手机、邮箱 |
| PUT | `/api/student/profile/password` | 登录学生修改本人密码、使原登录凭证失效 |

按用户本轮确认，修改密码仅填写新密码及确认密码，不要求原密码。仍必须持有本人有效的学生登录凭证，未登录、停用账号及其他角色不可使用。新密码至少 8 个字符、UTF-8 编码不超过 72 字节，两次输入必须一致，不能与原密码相同。密码使用现有 BCrypt 服务保存。成功后清除前端登录状态并进入登录页，其他用户的登录不受影响。此次设置页改版无需额外改表，不改动真实学生资料或密码。

## 轮播排查及样式

真实学生账号检查时，新闻 6、8 均已发布、开启轮播、具备官网及可读取的封面；列表及两张封面接口均正常，浏览器自动切换正常。旧新闻 4 未配置官网、封面及轮播开关，不会自动出现在轮播中。本次用户进一步明确问题为字幕影响图片美观。

参考小米商城首页轮播，移除图片上的标题、正文摘要、时间和黑色字幕遮罩；采用宽幅图片、两侧窄箭头及右下角圆点。标题和详情按钮置于图片下方。封面完整居中展示，点击封面在新标签页打开对应比赛官网；详情仍提供正文和官网入口。自动切换间隔为 5 秒，鼠标悬停时暂停。

现有封面包含表格截图，页面按原图显示，不自动替换管理员上传的图片。建议发布新闻时选用约 1226×460 的横幅海报。
