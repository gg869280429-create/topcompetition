# 2026-11-11 功能扩展实施计划

依据用户本轮18项完整需求开发；沿用Spring Boot/MyBatis/MySQL、Vue3/Element Plus现有模块。保留已有工作区改动，不自动提交或推送。所有新增业务迁移先在独立库验证，已有业务库上线执行仍须按此前约定单独确认。

## 约定

- 竞赛新增 `major_id` 仅分类，不影响可见范围和报名归属；旧值空，发布前补录。
- 指导状态增加 `COMPLETED`，与调剂/退赛的 `ENDED` 分开。ACTIVE占用名额，完成只释放一次，COMPLETED仍具备原指导学生必要查阅及成果申报权。
- 优先扩展现有award为成果申报，增加DRAFT、获奖学生及教师关联、四类证明材料、原团队名单快照。新申报每项真实成果唯一，允许同团队不同真实成果分别申报；旧成果保持原记录并标注旧资料需补录。
- 每位学生的参赛结果独立于报名状态和退赛审批。未参赛或未获奖不自动产生award。
- 新闻官网仅校验HTTP/HTTPS格式，不代替大赛官网真实性核验；不由后端访问任意地址。轮播需图片及官网，下线立即过滤。
- 庆祝以每项成果/教师唯一记录保存，展示前原子领取；已撤销不可领取，多项按顺序展示。
- 取消竞赛需在同事务检查有效成果、锁定关联业务、结束尚未完成指导、释放资格和待审流程、保留历史、发送通知。

## 分工与文件边界

1. 基础管理：module/major、module/user学生管理、competition DTO/entity/VO/service、专业/学生/竞赛/首页卡片前端。独立迁移003a，集成测试。首页新闻使用独立组件，交由新闻任务提供。
2. 新闻及文件：module/content、module/file、content前端及轮播组件。独立迁移003b，集成测试。向其他任务提供材料文件的安全上传和业务授权下载接口。
3. 成果：module/award、关联表、统计、获奖前端、庆祝组件；独立迁移003c，集成测试。与指导任务明确状态及权限契约。
4. 指导及整合：COMPLETED、指导快照、逐学生结果、名额增加/教师详情、取消关联业务；独立迁移003d；整合router/layout/dashboard、init.sql、全部迁移、测试和验收报告。
